## Setup

Xcode Command Line Toolsが必要。

```sh
./build
```

`/Applications/Plot.app` にインストールして起動される。

## Shortcuts

<details>
<summary>一覧</summary>

- 選択中のファイルをコピー — `⌘C`
- ウィンドウを閉じる — `⌘W`
- 常に手前に表示 — `⌥⌘T`
- データの選択 — 矢印キー
- 開く — `⌘O`
- 新規ウィンドウ — `⌘N`
- ウィンドウを複製 — `⇧⌘D`
- Finder で表示 — `⌥⌘R`
- エディタで開く（設定で変更可） — `⌘E`
- 絶対パスをコピー — `⌥⌘C`
- パネル画像を保存（Downloads へ） — `⌘S`
- X 軸の列を次へ／前へ — `⌘X` ／ `⇧⌘X`
- Y 軸の列を次へ／前へ — `⌘Y` ／ `⇧⌘Y`
- フィルタ画面を開く — `⌥⌘F`
- 外れ値除外を切り替え — `⇧⌥⌘R`
- 設定 — `⌘,`
- 次／前のウィンドウ — `` ⌘` `` ／ `` ⇧⌘` ``
- ウィンドウをタイル配置 — `⌥⌘A`
- 最小化 — `⌘M`

</details>
