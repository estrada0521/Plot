## Setup

Xcode Command Line Toolsが必要。

```sh
./build
```

`/Applications/Plot.app` にインストールして起動される。

## Shortcuts

<details>
<summary>file</summary>

| 操作 | キー | 備考 |
|---|---|---|
| 開く | `⌘O` | |
| 選択中のfileをコピー | `⌘C` | |
| 絶対pathをコピー | `⌥⌘C` | |
| Finderで表示 | `⌥⌘R` | |
| エディタで開く | `⌘E` | エディタは設定で変更可 |
| パネル画像を保存 | `⌘S` | Downloadsへ保存 |

</details>

<details>
<summary>plot</summary>

| 操作 | キー | 備考 |
|---|---|---|
| データの選択 | 矢印キー | |
| X軸の列を次へ / 前へ | `⌘X` / `⇧⌘X` | |
| Y軸の列を次へ / 前へ | `⌘Y` / `⇧⌘Y` | |
| フィルタ画面を開く | `⌥⌘F` | |
| 外れ値除外を切り替え | `⇧⌥⌘R` | |

</details>

<details>

| 操作 | キー | 備考 |

| 次 / 前のウィンドウ | `` ⌘` `` / `` ⇧⌘` `` | |

| ウィンドウをタイル配置 | `⌥⌘A` | |
| 最小化 | `⌘M` | |
| 設定 | `⌘,` | |

</details>
